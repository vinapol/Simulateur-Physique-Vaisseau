1. MASSIQUE, CENTRE DE MASSE & PROPULSION (src/physics/spacecraft.ts)

1.1 Masse Totale M_totale (tonnes)

M_totale = M_seche + M_ergols + M_cargaison
  • M_seche = M_poutre_base (22 t) + Σ(M_module_sec)
  • M_ergols = Σ(M_ergols_module) [LH₂ pour NTP / Argon pour NEP]
  • M_cargaison = Masse des caissons de fret (Méga-caissons)

1.2 Centre de Masse (CoM) sur l’axe longitudinal Z (mètres)

Z_CoM = Σ(M_i · Z_i) / M_totale

Positions Z des slots sur la structure du vaisseau :

  • Slot Avant : Z = +54,0 m
  • Slot Médian : Z = 0,0 m
  • Slot Intermédiaire : Z = -11,0 m (décalé à -26,0 m si Heavy Cargo monté)
  • Slot Arrière : Z = -50,0 m
  • Poutre nue seule : Z = -14,5 m

1.3 Équation de Tsiolkovski (Delta-v disponible initial)

Δv_dispo = Isp · g₀ · ln( M_totale / (M_seche + M_cargaison) )
  • g₀ = 9,80665 m/s² (accélération de la pesanteur standard)
  • Isp = Impulsion spécifique (912 s pour NTP, 4500 s pour NEP)

1.4 Poussée et Accélération Instantanée

F_reelle = F_nominale · Throttle (en Newtons)
a = F_reelle / (M_totale · 1000) (en m/s²)

3. TRANSFERT IMPULSIONNEL NTP (HOHMANN / CONJONCTION)

3.1 Géométrie de l’Ellipse de Hohmann

  • Demi-grand axe : a_Hohmann = (r₁ + r₂) / 2 = 1,26185 UA = 188,770 × 10⁹ m
  • Excentricité : e = (r₂ - r₁) / (r₂ + r₁) = 0,5237 / 2,5237 ≈ 0,20751

3.2 Temps de Transit Théorique vs Profil Étalonné

  • Temps de demi-ellipse théo : T_Hohmann = π · √( a³ / µ_⊙ ) ≈ 258,75 jours
  • Profil Conjonction DSTV-Liner : t_aller = 140 j ; t_retour = 140 j

3.3 Équation de Kepler & Position Instantanée r(t)

Pour t ∈ [0, t_transit] :

M(t) = π · (t / t_transit) [Anomalie moyenne]
E - e · sin(E) = M(t) [Équation de Kepler - Newton-Raphson]
ν(t) = 2 · atan2( √(1+e) · sin(E/2), √(1-e) · cos(E/2) ) [Anomalie vraie]
r(t) = a · (1 - e²) / (1 + e · cos(ν)) [Rayon héliocentrique]
v(r) = √( µ_⊙ · ( 2/r - 1/a_Hohmann ) ) [Vitesse Vis-Viva en m/s]

3.4 Décomposition du Budget Delta-v (4 manœuvres réelles)

  1. Trans-Mars Injection (TMI depuis HEO) : Δv_TMI = 3,60 km/s
  2. Capture Mars (Orbite haute aréocentrique) : Δv_cap_M = 1,10 km/s
  3. Trans-Earth Injection (TEI depuis Mars HEO) : Δv_TEI = 1,10 km/s
  4. Capture Terre (HEO / Point Lagrange EML-1) : Δv_cap_T = 1,00 km/s
Δv_total_NTP = 3,60 + 1,10 + 1,10 + 1,00 = 6,80 km/s
• Budget Transit Aller : Δv_aller = 4,70 km/s
• Budget Transit Retour : Δv_retour = 2,10 km/s

3.5 Synchronisation des Phases Orbitales (Rendez-vous exact Terre)

Condition d’alignement pour que la Terre et le vaisseau se croisent à t_arrivee :

(ω_Terre - ω_Mars) · t_sejour ≡ (Δθ_aller + Δθ_retour) - ω_Terre · (t_aller + t_retour) [mod 2π]

Formule exacte du temps de séjour martien t_sejour :
t_sejour = [ (2π - ω_Terre · (t_aller + t_retour)) mod 2π ] / (ω_Terre - ω_Mars) + k · T_synodique

4. TRANSFERT SPIRALE FAVORABLE NEP (PROPULSION IONIQUE ARGON)

4.1 Équation de la Spirale Logarithmique Héliocentrique

  • Balayage angulaire total : Δθ = 2,45 · 2π = 4,90 · π rad ≈ 15,3938 rad
  • Facteur de spirale k_NEP : k_NEP = ln(r₂ / r₁) / Δθ = ln(1,5237) / 15,3938 ≈ 0,02735
  • Rayon aller r(φ) : r(φ) = r₁ · exp( k_NEP · φ ) pour φ ∈ [0, Δθ]
  • Rayon retour r(φ) : r(φ) = r₂ · exp( -k_NEP · φ ) pour φ ∈ [0, Δθ]

4.2 Poussée Ionique Utile & Vitesse d’Éjection

ve = Isp · g₀ = 4500 · 9,80665 = 44 130 m/s
F = (2 · η · Puissance_Watts) / ve = (2 · 0,65 · Puissance_kW · 1000) / 44 130 (en Newtons)

4.3 Budget Delta-v Total NEP

• Transit Retour : Δv_retour = 4,50 km/s
